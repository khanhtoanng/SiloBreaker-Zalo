# Optional external integrations (Ponytail, Graphify, Superpowers)

All built-in SDLC behavior, conditional brainstorming, TDD and independent review work without external tools. Optional integrations are **opt in** and must never be installed just because the plugin runs.

1. Get user selection, scope and consequences. Check current upstream documentation, installation, permissions, hooks, data/network effects and supported host (Claude, Cursor, Codex) BEFORE proposing any enablement.
2. Ponytail may advise simplification, but cannot erase accepted behavior, TDD, security controls or independent review.
3. Graphify may assist dependency mapping across repositories; treat graph relationships as hypotheses checked against current source. Indexing, caching or hosted uploads need authorization.
4. Superpowers Brainstorming is a separate external skill; the plugin already performs conditional WHY/WHAT/HOW brainstorming through `roles.md`. Invoke upstream workflow only when explicitly selected and actually available.
5. Report `AVAILABLE | DISABLED | UNAVAILABLE | NOT VERIFIED` and real invocation evidence. If unavailable, continue with built-in behavior where safe. Do not invent cross-host invocation parity or silently copy upstream code.

Useful project references: https://github.com/Graphify-Labs/graphify ; https://github.com/obra/superpowers ; Ponytail: consult its current trusted upstream repository chosen by the user.
