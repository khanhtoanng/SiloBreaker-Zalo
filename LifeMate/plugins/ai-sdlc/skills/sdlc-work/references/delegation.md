# Delegation and independent review

<rules>
Roles are instruction contracts, not native subagent declarations. Coordinator may execute Intent/Spec/Architect/Developer DIRECT when efficient and authorized. A task may be delegated when real context isolation, independent investigation or nonconflicting parallel work is useful; verify actual dispatch and results, don't just state that one happened.

After *any code change*, `AI_PASS` requires a new independent reviewer context that did not implement the changed code, received accepted ACs and an identifiable current snapshot, and inspected the relevant diff and checks. Reviewer findings must be verified and any fixes reviewed again (max three AI repair loops before owner escalation). Read-only is a desired behavior, but only real host permission/tool restrictions enforce it. Do not give a reviewer write access merely to collect evidence.
</rules>

<host-capabilities>
- **Claude Code:** use actual Agent/subagent tools if present. The bundled `agents/sdlc-reviewer.md` prefers read/grep/glob. If reviewer cannot run shell, Coordinator supplies exact Git diff and test output, plus relevant new/untracked contents. Validate the subagent truly ran.
- **Cursor:** use actual subagent/Task workflow if available, with bundled `agents/sdlc-reviewer.md`. Confirm host-native reviewer discovery and actual invocation; do not assume `readonly` instructions enforce filesystem isolation. Separate workspace roots must be available to the reviewer.
- **Codex:** use actual subagents (supported local sessions) for a fresh reviewer context; custom `.codex/agents/*.toml` is optional project-owned configuration and NOT generated by default. Codex subagents inherit parent sandbox/approval settings; a reviewer prompt alone is not a read-only sandbox. A dedicated `codex review` on an exact snapshot may provide additional evidence but do not treat it as an independent subagent unless actual isolation is observed.
- If no separate independent review is available, report `REVIEW: NOT VERIFIED` / `INDEPENDENCE: NOT VERIFIED` and ask for a human or supported review path; cannot emit `AI_PASS`.
</host-capabilities>

<reviewer-output>
Status: `AI_PASS | CHANGES_REQUESTED | BLOCKED`; independence `VERIFIED | NOT VERIFIED`; per-root reviewed branches/HEAD/diffs and relevant untracked contents; AC coverage including cross-repo integration; exact observed test/TDD evidence; actionable findings with severity/file/line and expected-vs-actual; unresolved risks and human gates. Reviewer cannot authorize code edits, Git actions, merge, Terraform apply or deployment.
</reviewer-output>
