not disable it. Old workflow meanings/entrypoints are retained and migration changes
are explicit in the guide. All original tests/assertions are retained.

SDK validate/call. Controlled dependencies/conditions, internal binding and pending
occurrences govern writes; real effects complete them, unknown outcomes quarantine,
completed writes cannot repeat, deliberate distinct equal requests remain possible,
and banking no-effect recovery requires exact cause-linked new actual evidence and
bounded attempts. ASK is the real authorized terminal meta call; DONE stays internal
with bounded reconsideration. No inference state getter or gold decision input.

Whisper code validates PCM/readability/rate/duration, converts mono and resamples;
**30 seconds per WAV is the current supported short-form maximum**, with explicit
failure rather than truncation above it. Sample clock normalization retains spans,
corrections, uncertainty and original text. Real semantic/ASR quality is unmeasured.
